# ATLANTA CAM

Правь исходники в `src/`. Точку входа ищи в `src/main.js`. Для конкретной задачи открывай нужный раздел [документации по разработке](docs/DEVELOPMENT.md) или [карты модулей](docs/ARCHITECTURE.md).

- Интерфейс и состояние находятся в `src/app/`, `src/ui/` и `src/styles/`.
- Геометрия, траектории и операции находятся в `src/core/`, `src/geometry/`, `src/cam/` и `src/operations/`.
- Разбор и генерация NC находятся в `src/nc/`. Проверки лежат в `tests/unit/` и `tests/browser/`.

В Termux запускай `bash scripts/check.sh` для проверки Git diff и синтаксиса Bash. Установка npm-зависимостей, Prettier, проверки архитектуры, тесты и сборка выполняются в GitHub Actions. Правь файлы из текущей задачи. Сохраняй эталоны `tests/fixtures/`, пока изменение ожидаемого поведения явно не согласовано.

Если отправка согласована, добавь в индекс только файлы задачи через `git add -- <пути>` и проверь `git diff --cached --stat`. Затем выполни `bash scripts/push.sh "Сообщение коммита" && bash scripts/ci.sh`. Скрипт дождётся CI именно для текущих ветки и коммита. При ошибке сначала прочитай вывод упавшего шага. Полный отчёт и патч Prettier скачивай из `atlanta-cam-reports`, когда они нужны.

В итоговом ответе укажи коммит и подтверждённый результат CI.
