# ATLANTA Контур 3.89

Автономное приложение для построения контуров, назначения операций и подготовки NC для FANUC 3000C. В версии 3.89 добавлена привязка Z по плитке и радиусу фрезы. Модульные исходники, сборка и тесты сохранены в отдельных папках.

## Запустить программу

Скачайте `atlanta-cam-release` из [GitHub Actions](https://github.com/Ncorror/ATLANTA-CAM/actions/workflows/ci.yml) и откройте `ATLANTA-Contour-Offline-3.89.html` в браузере. Для работы готовой программы Node.js, установка зависимостей и интернет не нужны.

Проект из предыдущей версии переносится через сохранённый JSON: «Сохранить проект» в старом файле → «Открыть» в новом. Автосохранение локальных HTML может зависеть от браузера и адреса файла.

## Привязать Z по плитке

Во вкладке «Обработка» раскройте «Привязка Z». Укажите высоту плитки, выберите поверхность касания и ноль детали. Для описанной установки: «Ноль сверху слева», плитка 30 мм, фреза Ø10 мм. Результат:

```text
G92X0Y0Z35000 (Plitka = 30)
```

Формула: `Z поверхности относительно нуля + высота плитки + диаметр / 2`. Радиус берётся из выбранного инструмента. Для нового чертежа режим включён; в загруженных прежних проектах он выключен до явного включения. Подробности и разбор присланного NC — в [отчёте о привязке Z](docs/Z-REFERENCE.md).

## Начать разработку

Нужны Node.js 22.13+ и npm; проверено на Node.js 24.22.3. Все команды выполняются в этой папке.

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. При изменении `src/` сборка обновляется автоматически; страницу нужно обновить вручную. Другой порт задаётся переменной `PORT`.

```sh
npm run build        # собрать автономный HTML и версию для разработки
npm run test:unit    # расчётные тесты без браузера
npm run check        # синтаксис, импорты и границы модулей
npm run format      # единое форматирование исходников
```

Для полного прогона установите тестовый браузер один раз:

```sh
npx playwright install chromium
npm test
```

Можно использовать установленный Microsoft Edge. В PowerShell:

```powershell
$env:BROWSER_CHANNEL = "msedge"
npm test
npm run package
```

`npm test` проверяет форматирование, архитектуру, расчёты, затем собирает приложение и проверяет готовый HTML в браузере. `npm run package` повторяет полный прогон и создаёт ZIP в `releases/`. Зависимости и временные файлы в ZIP не попадают.

## Что находится в папке

```text
src/                  Исходники — изменять здесь
  app/                Состояние, параметры и управление приложением
  core/               Математика, плоскости, сегменты и контуры
  geometry/           Построения, пересечения, привязки, восстановление
  cam/                Планирование траекторий и профиль станка
  nc/                 Разбор, формирование и просмотр команд NC
  operations/         Инструменты, проходы, G12/G13, G25, M98
  persistence/        Восстановление параметров операций
  workers/            Фоновый расчёт и общий исполнитель
  ui/                 Редактор, отображение, HTML-фрагменты
  styles/             Стили с явно заданным порядком каскада
  platform/           Совместимость браузера и прежний публичный API
  data/               Каталог инструментов и примеры
scripts/              Сборка, сервер разработки, проверки, упаковка
tests/                Расчётные и браузерные тесты, неизменные эталоны
docs/                 Архитектура, правила разработки и история
examples/             Исправленный пример привязки присланной программы
dist/                 Готовая программа и сборка для отладки
reports/              Результаты последней полной проверки
```

Не редактируйте `dist/` вручную: при сборке он создаётся из `src/`. Зависимости разработки зафиксированы в `package-lock.json`; у готового HTML внешних зависимостей нет.
