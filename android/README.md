# Нативная версия ATLANTA CAM

Kotlin/JVM-модуль содержит расчёт привязки Z для FANUC 3000C. Он вычисляет
положение физического центра фрезы в рабочей системе координат и формирует
блок `G92` с точностью 0,001 мм. Высота плитки 30 мм и диаметр фрезы 10 мм
при касании на Z0 дают `G92X0Y0Z35000` с комментарием `(Plitka = 30)`.
Для проектов с выключенной или отсутствующей настройкой доступна прежняя
привязка `G92X0Y0Z30000`.

## Проекты JSON формата 5

`ProjectV5Codec.decode(text)` читает сохранённый проект, а `encode(project)`
возвращает JSON для записи в файл. `fromJson(document)` проверяет основную
структуру после редактирования. Кодек сохраняет порядок операций, настройки,
эскиз, DXF, текст NC и неизвестные поля, включая исходное различие между
числом и строкой. Счётчик новых операций вычисляется при чтении. Исходное
поле счётчика сохраняется при экспорте.

В загруженной операции привязку по плитке включает только `true` в её
параметрах. Отсутствующая настройка оставляет прежнюю привязку. Кодек
проверяет маркер формата, структуру проекта и идентификаторы операций и
инструментов. Для сохранённых эскизов геометрию проверяет `sketchScene`
при построении контуров.

## Рабочие плоскости и сегменты

`WorkPlane` преобразует локальные координаты в оси станка и обратно для
XY/G17, ZX/G18 и YZ/G19. При переносе блока NC он сопоставляет оси и адреса
центра дуги, а в ZX также меняет направление дуги и сторону коррекции.
Блоки G25 и G92 сохраняются целиком. Поддерживаются окончания строк LF,
CRLF и одиночный CR.

`LineSegment` и `ArcSegment` описывают отрезки и дуги в локальной плоскости.
Для них доступны длина, точка и касательная, разворот, расстояние до точки,
аппроксимация точками, габариты и знаковая площадь. Дуги можно строить по
трём точкам или по параметру bulge из DXF. Угол дуги задаётся в радианах,
положительное направление идёт против часовой стрелки.

`connectSegments` соединяет совпадающие концы и закрывает зазоры в пределах
допуска, отмечает разветвления и определяет вложенность закрытых контуров.
`ProjectV5.sketchScene` собирает общий план, контуры фрезерной операции и
центры сверления по отметкам сохранённых элементов.

## Импорт DXF

`readDxf` читает геометрию XY из ASCII DXF. Поддерживаются LINE, ARC,
CIRCLE, LWPOLYLINE, POLYLINE, SPLINE, ELLIPSE и вставки BLOCK/INSERT.
Сплайны и эллипсы аппроксимируются отрезками. Координаты приводятся к
миллиметрам по `$INSUNITS`. Если единицы отсутствуют, принимаются
миллиметры и показывается предупреждение. Стыковка и удаление дубликатов
выполняются внутри слоёв. Диагностика перечисляет пропущенные сущности.

Приложение открывает DXF через системный диалог и показывает число контуров
и слоёв. В проекте JSON v5 встроенный DXF отображается с сохранёнными
настройками масштаба, если в файле отсутствует сохранённый эскиз.

## Android-приложение

Debug APK открывает DXF и проекты JSON v5, показывает чертёж и геометрию
выбранной операции. Синим выделяются контуры профиля, оранжевым — центры
отверстий.

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Из каталога
`android/` запустите `./gradlew -p app :assembleDebug`. APK появится в
`app/build/outputs/apk/debug/atlanta-cam-android-debug.apk`. Минимальная версия Android — 8.0.
При подключённом устройстве или запущенном эмуляторе команда
`./gradlew -p app :connectedDebugAndroidTest` устанавливает APK и
проверяет загрузку JSON и DXF, смену операции и обработку повреждённого файла.
GitHub Actions публикует проверенный APK в артефакте `atlanta-cam-android-debug`.

## Сборка и тесты

Используйте JDK 17. Из каталога `android/` выполните `./gradlew build`
на Linux и macOS или `gradlew.bat build` на Windows. Тесты проверяют выбор
поверхности, округление, пределы координат и совместимость со старой привязкой,
чтение и сохранение исходных фикстур из `tests/fixtures/`, преобразования рабочих
плоскостей, расчёты для отрезков, дуг и полных окружностей, стыковку сегментов
восстановление геометрии проекта и чтение DXF со слоями и блоками.
