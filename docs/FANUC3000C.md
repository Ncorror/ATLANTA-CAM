# Сохранённый контракт FANUC 3000C

В рефакторинге 3.88 сохранено поведение исправленной версии 3.87. В 3.89 добавлена настраиваемая физическая привязка Z. Основание прежней сверки команд — предоставленный пользователем `Fanuc3000c.pdf`; параметры установки по плитке взяты из последующего пояснения Влада и схемы. Подробные исправления команд и номера страниц находятся в [отчёте 3.87](reference/changes-3.87.txt). Сам PDF не включён в архив исходников.

| Область                  | Правило, закреплённое в тестах                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| XY / G17                 | Горизонталь X, вертикаль Y, углубление Z                                                             |
| XZ / G18                 | Горизонталь X, вертикаль Z, углубление Y; учитывается ориентация дуг                                 |
| YZ / G19                 | Горизонталь Y, вертикаль Z, углубление X                                                             |
| Начальная установка      | G92 всегда содержит физические X/Y/Z. Прежний режим: Z30000; по плитке: Z поверхности + плитка + D/2 |
| Дискретность профиля     | 1 мм = 1000 отсчётов; F100 = 10 мм/мин                                                               |
| Центр дуги               | I/J/K относительно начала дуги                                                                       |
| G25                      | P–Q включительно; R — дополнительные исполнения; оба смещения реверсной пары входят в диапазон       |
| Ограничения повторов     | Запрещены G25 внутри M98 и вложенная G25                                                             |
| G12/G13                  | XY, радиус пути равен `abs(I) − корректор`; текущая подача, возврат в центр                          |
| D/H                      | Один номер обращается к одному значению корректора                                                   |
| M98/M99                  | Сохранение модальных команд и проверка адресов, корректировка ссылок при перенумерации               |
| Неподдерживаемые команды | Явная диагностика вместо молчаливого исключения из траектории                                        |

Значение корректора в комментарии `ATLANTA D…` нужно просмотрщику. Оно не записывает таблицу коррекции стойки. Модель формы фрезы остаётся моделью плоского контура с глубиной контакта, а не полной трёхмерной проверкой зажимов и державки.

При верхнем нуле, плитке 30 мм и сферической фрезе Ø10 новая привязка даёт `G92X0Y0Z35000 (Plitka = 30)`. Перенос исходного примера требует изменить также первое приращение G91; обоснование и полный пример находятся в [отчёте о привязке Z](Z-REFERENCE.md).

Параметры конкретной комплектации станка, исполнение на станке и Windows 7 / старый Firefox в этом выпуске не проверялись.
