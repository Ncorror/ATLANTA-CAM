# Результат рефакторинга 3.88

Исторический отчёт о версии 3.88. Новая привязка и изменения 3.89 описаны отдельно в [Z-REFERENCE.md](Z-REFERENCE.md).

## Что мешало дальнейшей разработке

Приложение поставлялось одним большим HTML с 26 встроенными скриптами. Даже небольшое изменение требовало искать код среди интерфейса, стилей, геометрии, обработки и данных. Модули получали зависимости через глобальные объекты; результат некоторых функций зависел от того, был ли позже загружен скрипт, подменяющий их реализацию. Фоновый расчёт собирался из помеченных участков документа и повторял часть кода запасного пути.

Рабочий формат одного HTML удобен оператору. Для разработчика нужен отдельный исходный проект с понятными границами и сборкой. В версии 3.88 эти две формы существуют вместе.

## Что изменено

- Выделены 91 ES-модуль: расчётное ядро, геометрия, NC, операции, редактор, состояние, хранение, платформа и фоновые задачи.
- В расчётных модулях глобальные зависимости заменены прямыми импортами. Циклы импортов устранены и автоматически проверяются.
- Удалена подмена функций разбора NC, извлечения геометрии и формирования кадров при загрузке соседних скриптов. Эти связи теперь заданы обычными импортами и функциями.
- Разбор арифметических выражений доступен без предварительного создания редактора.
- Контроллеры приложения и редактора получают явный контекст состояния и обработчиков. Схемы полей и начальное состояние вынесены отдельно.
- HTML разделён на макет, панели и диалоги; CSS — на десять тематических файлов с сохранением исходного порядка правил.
- Worker собирается из обычной точки входа. Фоновый и запасной расчёт выполняют одну функцию; добавлена проверка полного совпадения их результатов и отмены отложенного расчёта.
- Добавлены переносимые сборка, локальный сервер, форматирование, проверка архитектуры и упаковка ZIP.
- Зависимости зафиксированы в lock-файле. Автономный HTML сохраняет работу без интернета.
- Тесты перенесены в проект, отделены от временных файлов и личных путей. Добавлены неизменные эталоны 3.87, изоляция браузерных сценариев и протокол релизной проверки.

## Что проверяется

Расчётный набор содержит 101 тест, включая 34 сравнения с версией 3.87 по полному NC-коду и всем полям движений. Браузерный и сборочный набор содержит 25 тестов: интерфейс, проекты, ошибки загрузки/сохранения, Worker, отмена, DOM и автономная сборка. Полный прогон также проверяет форматирование, синтаксис, импорты и отсутствие обращения расчётного слоя к браузерному.

Фактический результат, дата, среда и SHA-256 версии 3.88 находятся в [verification-3.88.json](reference/verification-3.88.json). Протокол текущего выпуска находится в `reports/verification.json`. Число тестов отличается от отчёта 3.87: прежние сценарии перенесены в стандартный тестовый раннер, часть проверок объединена, добавлены проверки структуры и неизменности результатов.

Архив 3.88 дополнительно распакован в новую папку с пробелами и кириллицей. После чистого `npm ci` повторно прошли все 126 тестов. Сборка, вызванная из другой рабочей папки, дала тот же SHA-256 автономного HTML. Проверены локальный сервер, запуск страницы в браузере и автоматическая пересборка при изменении исходника. Протокол: [portability-3.88.json](reference/portability-3.88.json).

## Оценка состояния программы

Теперь проект можно развивать по отдельным областям, проверять изменения до выпуска и собирать готовый файл повторяемым способом. Исходный файл пользователя и версия 3.87 не перезаписывались. Математическое поведение и формат проектов сохранены.

Рефакторинг не доказывает корректность для любых входных данных. В корнях интерфейса ещё остаётся связывание обработчиков, а интерпретатор и планировщик радиусной коррекции содержат крупные алгоритмы. Их дальнейшее деление стоит проводить при конкретных изменениях под защитой эталонных тестов. Новые функции станка и полноценная объёмная проверка столкновений требуют отдельных задач и исходных данных. Привязка Z реализована позднее в 3.89 после уточнения установки пользователем.
